🏕️ Types of Camps
🎯 Autism-specific camps
🌈 Inclusive mainstream camps
🎨 Special interest camps (STEM, art)

💻 Virtual camps (sensory-safe)
❓ Questions to Ask
→ What's the staff-to-camper ratio?
→ How are staff trained on autism?
→ Is there a quiet/sensory space?
→ How do you handle meltdowns?
→ Can we do a trial day first?
🚩 Red Flags
✕ "We treat everyone the same"
✕ No accommodation flexibility
✕ Won't let you visit first
✕ Vague about training
✕ Dismissive of concerns
✕ No sensory plan
✅ Green Flags
✓ Asks detailed questions
✓ Has worked with autistic kids
✓ Welcomes parent input
✓ Visual schedules used
✓ Flexible on sensory needs
✓ Communication plan in place
