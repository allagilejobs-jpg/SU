📱 AAC OPTIONS
📱
High-Tech
Tablets with speech apps (Proloquo2Go, TouchChat)
📋
Low-Tech
Picture boards, PECS, communication books
🤟
Sign Language
ASL or personalized gestures
✏️
Writing/Typing
Letter boards, keyboards
✅ HOW TO SUPPORT AAC SUCCESS
✓ Model it yourself
✓ Keep AAC available 24/7
✓ Give 10-15 sec wait time
✓ Honor ALL attempts
✓ Never withhold to "make them talk"
✓ Presume competence
💥 MYTHS BUSTED
✓ AAC does NOT prevent speech
✓ No prerequisites needed
✓ Never "too young" for AAC
✓ Can use alongside speech
💙 Communication is a RIGHT, not a privilege.
