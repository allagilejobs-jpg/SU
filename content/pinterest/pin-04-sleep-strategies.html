🌙 Sleep Help

Sleep Issues in Autism:
What Actually Helps

📊 50-80% of autistic kids have sleep problems

🧠 WHY SLEEP IS HARDER
• Different melatonin production
• Hard to wind down an active nervous system
• Sensory sensitivities (sheets, sounds, light)
• Co-occurring anxiety
🏠 ENVIRONMENT FIXES
✓ Total darkness (blackout curtains)
✓ White noise machine
✓ Weighted blanket
✓ Cool room (65-68°F)
✓ Cover all LED lights
✓ No screens 1-2h before bed
📋 ROUTINE MATTERS
✓ Same time every night
✓ Visual bedtime schedule
✓ Predictable sequence
✓ Same comfort items
💾 Save for those exhausted nights!
