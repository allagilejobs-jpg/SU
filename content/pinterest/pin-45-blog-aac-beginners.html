AAC for Beginners

A Parent's Guide to Augmentative Communication

Myth: AAC prevents speech.
Truth: Research shows it SUPPORTS speech development.
💬 Types of AAC
📱 High-tech apps (Proloquo2Go)
📋 Low-tech boards (PECS)
🤟 Sign language
🖼️ Picture exchange
🚀 How to Start Today
1. Model AAC yourself — use it while talking
2. Start with motivating words (snack, play, more)
3. Accept ALL communication attempts
4. Don't require perfection — respond to any try
✅ Signs It's Working
✓ Less frustration and fewer meltdowns
✓ Child initiates communication
✓ More connection and engagement
